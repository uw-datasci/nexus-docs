# UI Package

The shared design system built with shadcn/ui components.

## Overview

The `@uwdsc/ui` package contains all shared UI components (atoms) used across the monorepo.

**Location**: `packages/ui/`

**Import**: `@uwdsc/ui`

## Available Components

The full list, one file per component in `packages/ui/src/components/`:

### Layout & Structure

- **Card** - Container with border and padding
- **Separator** - Visual divider
- **Scroll Area** - Custom-styled scrollable region
- **Sidebar** - App sidebar layout primitive
- **Collapsible** - Expand/collapse content

### Navigation

- **Navigation Menu** - Accessible navigation
- **Tabs** - Tabbed interfaces

### Form Components

- **Button** - Interactive buttons with variants
- **Input** - Text input fields
- **Textarea** - Multi-line text input
- **Checkbox** - Boolean input
- **Radio Group** - Single-choice input
- **Switch** - Toggle input
- **Select** - Dropdown selection
- **Form** - Form wrapper with validation (React Hook Form)
- **Datetime Picker** / **Calendar** / **Event Calendar** - Date and event selection
- **Label** - Form field labels

### Feedback

- **Badge** - Status indicators
- **Sonner** - Toast notifications (this project uses `sonner`, not a separate Toast component)
- **Skeleton** - Loading placeholders
- **Spinner** - Loading indicator
- **Tooltip** - Contextual hints

### Overlays

- **Dialog** - Modal dialogs
- **Dropdown Menu** - Contextual menus
- **Popover** - Floating content
- **Sheet** - Side panels

### Data Display

- **Avatar** - User avatars
- **Table** - Data tables
- **Accordion** - Collapsible content
- **Chart** - Recharts-based charts
- **Carousel** - Content carousel
- **Counting Numbers** - Animated number counter
- **Toggle** - Toggle button

### Marketing / Visual

- **Galaxy Hero**, **Glass Surface**, **Section Title** - Site-specific visual/marketing components

## Installation

### Adding New Components

Use the custom script from the root:

```bash
pnpm ui:add <component-name>
```

**Examples:**

```bash
# Add a dialog component
pnpm ui:add dialog

# Add multiple components
pnpm ui:add dropdown-menu popover sheet
```

This script:
1. Runs `pnpm dlx shadcn@canary add <component-name>` from `packages/ui`
2. Downloads the component to `src/components/` and installs its dependencies
3. Diffs the component directory before/after and appends `export * from "./components/<name>"` to `src/index.ts` for any newly created file(s)
4. If it can't detect a new file, it prints the export line to add manually - check `src/index.ts` after running if the command output looks unusual

### Manual Installation

If you need to install manually:

```bash
cd packages/ui
pnpm dlx shadcn@canary add <component-name>
```

## Usage

### Basic Import

```tsx
import { Button, Card, CardHeader, CardContent } from "@uwdsc/ui";

export function MyComponent() {
  return (
    <Card>
      <CardHeader>Title</CardHeader>
      <CardContent>
        <Button>Click me</Button>
      </CardContent>
    </Card>
  );
}
```

### With Variants

```tsx
import { Button } from "@uwdsc/ui";

export function ButtonExample() {
  return (
    <div className="flex gap-2">
      <Button variant="default">Default</Button>
      <Button variant="outline">Outline</Button>
      <Button variant="ghost">Ghost</Button>
      <Button variant="destructive">Destructive</Button>
    </div>
  );
}
```

### With Sizes

```tsx
import { Button } from "@uwdsc/ui";

export function SizeExample() {
  return (
    <div className="flex gap-2 items-center">
      <Button size="sm">Small</Button>
      <Button size="default">Default</Button>
      <Button size="lg">Large</Button>
    </div>
  );
}
```

## Styling

### Tailwind Classes

All components accept `className` prop:

```tsx
<Button className="mt-4 w-full">
  Full Width Button
</Button>
```

### CSS Variables

Components use CSS variables for theming:

```css
:root {
  --background: 0 0% 100%;
  --foreground: 222.2 84% 4.9%;
  --primary: 222.2 47.4% 11.2%;
  --primary-foreground: 210 40% 98%;
  /* ... more variables */
}
```

### Dark Mode

Automatically supports dark mode:

```tsx
import { ThemeProvider } from "next-themes";

function App({ children }) {
  return (
    <ThemeProvider attribute="class" defaultTheme="system">
      {children}
    </ThemeProvider>
  );
}
```

### Form Component

```tsx
import { useForm } from "react-hook-form";
import { zodResolver } from "@hookform/resolvers/zod";
import { z } from "zod";
import {
  Form,
  FormField,
  FormItem,
  FormLabel,
  FormControl,
  FormMessage,
  Input,
  Button,
} from "@uwdsc/ui";

const formSchema = z.object({
  email: z.string().email(),
});

export function FormExample() {
  const form = useForm({
    resolver: zodResolver(formSchema),
  });

  return (
    <Form {...form}>
      <form onSubmit={form.handleSubmit(onSubmit)}>
        <FormField
          control={form.control}
          name="email"
          render={({ field }) => (
            <FormItem>
              <FormLabel>Email</FormLabel>
              <FormControl>
                <Input placeholder="email@example.com" {...field} />
              </FormControl>
              <FormMessage />
            </FormItem>
          )}
        />
        <Button type="submit">Submit</Button>
      </form>
    </Form>
  );
}
```

## Utilities

### cn() Function

Merge Tailwind classes:

```tsx
import { cn } from "@uwdsc/ui/lib/utils";

<div className={cn(
  "base-classes",
  isActive && "active-classes",
  className
)} />
```

### Custom Hooks

```tsx
import { useIsMobile } from "@uwdsc/ui";

export function Component() {
  const isMobile = useIsMobile();
  return <div>{isMobile ? "Mobile layout" : "Desktop layout"}</div>;
}
```

### Toasts (sonner)

Toasts use [sonner](https://sonner.emilkowal.ski/) directly, not a custom hook. Render `<Toaster />` (re-exported from `@uwdsc/ui`) once near the app root, then call `toast()` from `sonner` anywhere:

```tsx
// app/layout.tsx
import { Toaster } from "@uwdsc/ui";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        {children}
        <Toaster />
      </body>
    </html>
  );
}
```

```tsx
import { toast } from "sonner";

export function Component() {
  return <Button onClick={() => toast.success("Action completed successfully")}>Show Toast</Button>;
}
```

## Best Practices

### ✅ Do

- Import components from `@uwdsc/ui`
- Use provided variants and sizes
- Extend with Tailwind classes
- Follow accessibility guidelines
- Use semantic HTML

### ❌ Don't

- Modify component files directly
- Create duplicate components in apps
- Override core styles excessively
- Ignore accessibility features

## Customization

### Extending Components

Create custom variants:

```tsx
import { Button } from "@uwdsc/ui";
import { cn } from "@uwdsc/ui/lib/utils";

export function CustomButton({ className, ...props }) {
  return (
    <Button
      className={cn("custom-gradient shadow-lg", className)}
      {...props}
    />
  );
}
```

### Theme Customization

Modify CSS variables in `globals.css`:

```css
:root {
  --primary: 200 100% 50%;  /* Custom primary color */
}
```

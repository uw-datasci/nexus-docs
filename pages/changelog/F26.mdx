# Fall 2026 Updates

Work across the UWDSC applications. Details will grow as PRs land through the term.

## 🎯 Main Website

- **Automated Code Review Requests**: Website changes now automatically request review from the VP Development team, helping route updates to the appropriate reviewers.
- **Improved authentication experience**: Users can move through sign-in, registration, email verification, password recovery, and profile setup on consistent, responsive pages with clear navigation back to the home page.
- **Smoother mobile navigation**: Mobile users are returned to the page after selecting a menu link, making site navigation faster and less cluttered.
- **Shared app error monitoring**: Website and admin routes now use a shared error-tracking setup that captures production failures and returns cleaner responses, helping the team spot and fix issues faster.

## 🧮 Estimathon

- **Automatic VP Dev review requests**: Changes to the Estimathon application now automatically request review from the VP Dev team, helping ensure the right technical owners are included.
- **Shared error monitoring standards**: Improved the shared Raft SDK guidance so apps report errors consistently, deduplicate production alerts, and keep route failures easier to diagnose.

## 🏆 CxC

- **Automatic Code Review Requests**: CxC changes now automatically request review from the VP of Development team, helping route updates to the right maintainers.
- **Coming Soon Landing Page**: Visitors see a branded CxC page announcing that Winter 2027 details will be shared shortly.
- **Sponsor Contact**: Prospective sponsors can contact the outreach team directly from the landing page.
- **Pre-launch Access**: While the event is being prepared, visitors see the coming-soon page instead of unfinished application and account pages.
- **Shared app reliability standards**: Updated the CxC app’s route and error-handling guidance so submissions and admin workflows follow a consistent, production-safe pattern with clearer failure handling.

## 💘 Speed Dataing

- **Automatic VP Development review requests**: Speed Dataing pull requests now automatically request review from the VP Development team, supporting timely oversight and consistent project quality.

## 🛠️ Admin

- **Discord event drafting**: Execs can use `/event-create` in a planning thread to generate, review, and confirm an event draft, which admins can publish from the Events page when it is ready.

## 🎃 DSC Hunt

- **Home page navigation**: Signed-in players can enter the hunt at the correct stage based on its current status.
- **Team lobby riddle access**: Team members can use the “Click here to see riddles” button once the hunt is live.
- **Team Riddle Progress**: Teams can reveal and solve riddles one at a time, track solved and visited locations, and see progress update live for all teammates.
- **Event Leaderboard**: Users can view teams ranked by total score, with ties awarded to the team that reached its score first.
- **Location visit scoring**: Teams earn points for confirmed location visits, with higher rewards for earlier visits and live score updates for teammates.
- **Riddle card flip**: Players can reveal riddles through interactive cards, submit answers, and see completed locations clearly.
- **Progressive riddle unlocking**: Solving a riddle and scanning its location QR code unlocks the next riddle for the team.
- **Team creation and joining**: Players can create a named team and share its five-digit code, or join an existing team with a teammate's code.
- **Team management**: Players can view their live team roster and leave before the hunt starts, while staff can review teams, rename them, remove members, or delete teams before the hunt begins.
- **More reliable event workflows**: Improved the app’s shared error-handling guidance so failures in DSC Hunt flows surface clearly and are easier to fix during live operations.
